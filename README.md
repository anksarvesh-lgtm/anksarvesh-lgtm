## What I'm building

- 🌾 **[Agrigence](https://www.agrigence.in)**: a platform for agriculture in India. It includes an open-access research journal and exam preparation for agriculture competitive exams.
- 🍎 **[dynamo-mac](https://github.com/anksarvesh-lgtm/dynamo-mac)**: turns the MacBook notch into a small control center (media, devices, smooth animations). Built in Swift.
- 🛡️ **[agent-guard](https://github.com/anksarvesh-lgtm/agent-guard)**: a local MCP server that keeps AI coding agents running reliably. No telemetry. Built in Python.
